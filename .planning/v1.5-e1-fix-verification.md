## 수정 내용

1. `engine/src/main/java/io/github/nini4746/cdcview/cdc/CdcTopicProvisioner.java` (신규, @Order 15): Streams 기동 전 뷰 정의 소스 테이블에서 파생한 CDC 토픽 (`ConnectProperties.topicFor`, TopologyBuilder 구독명과 동일 규칙) 을 AdminClient로 멱등 선생성. 파티션 1 / RF 1 (브로커 auto-create 기본 및 streams replication.factor=1과 동일 형상). TopicExists는 성공 취급, 그 외 실패는 30초 타임아웃 + 부팅 중단 (fail-fast). `bootstrap.streams=false` 면 생략.
2. `engine/src/main/java/io/github/nini4746/cdcview/topology/StreamsManager.java`: `setUncaughtExceptionHandler` 추가. cause 체인에 MissingSourceTopicException 이 있으면 REPLACE_THREAD (잔여 메타데이터 경합 방어), 그 외는 기존 기본 동작 SHUTDOWN_CLIENT 유지.

## 환경 메모 (재현 절차 포함)

- 이번 실측에서는 호스트 8080이 비어 있어 (V1 때 점유하던 streaming-site 종료됨) README 절차를 원본 포트로 그대로 실측했다.
- **8080 충돌 시 우회 절차** (V1에서 사용): 아래 override 파일을 만들어 `-f` 로 겹쳐 실행하면 컨테이너 구성 변경 없이 호스트 포트만 바꿀 수 있다. demo-check.sh 는 8080 하드코딩이라 이 경우 수동 curl로 확인해야 한다 (관찰 O2, REST 환경변수화 후보).

  ```yaml
  # port-override.yml
  services:
    engine:
      ports: !override
        - "18080:8080"
  ```
  ```bash
  docker compose -f docker-compose.yml -f port-override.yml up -d --build
  curl -s http://localhost:18080/views/seller-dashboard/1 | jq
  ```
- 로컬 gradle 실행 시 호스트 기본 JDK가 25라 Gradle 8.10.2가 못 돈다. `JAVA_HOME=$(/usr/libexec/java_home -v 21)` 지정 필요 (컨테이너 빌드는 무관).
- `ReplicaIdentityCheckerIT` 는 testcontainers(docker-java) 가 구식 Docker API 버전 (1.32) 으로 협상해 최신 Docker Desktop (최소 1.40) 이 400을 반환하는 환경 문제로 실패한다. `DOCKER_API_VERSION=1.44 ./gradlew :engine:test --tests ReplicaIdentityCheckerIT` 로 통과 확인 (코드 결함 아님). 근본 해결은 testcontainers 버전 업 (별도 정비 항목).
